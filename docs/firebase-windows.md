# راه‌اندازی اعلان گوشی (Firebase) — راهنمای ساده برای ویندوز

بدون این مراحل هم اپ کار می‌کند و «مرکز اعلان» داخل اپ (زنگوله) پر می‌شود؛ فقط اعلانی روی صفحه‌ی گوشی نمی‌آید.
این کار را یک بار انجام می‌دهید. **هیچ‌کدام از این دو فایل را در گیت‌هاب (کد) نگذارید و برای کسی نفرستید.**

> سایت Firebase از ایران معمولاً بدون فیلترشکن باز نمی‌شود.

## ۱) ساخت پروژه
1. به `https://console.firebase.google.com` بروید و با جیمیل وارد شوید.
2. «Create a project» ← نام: `hamshagerdi` ← Google Analytics را خاموش کنید ← Create.

## ۲) فایل اپ اندروید (google-services.json)
1. در صفحه‌ی پروژه، آیکن اندروید را بزنید (Add app ← Android).
2. Android package name را دقیقاً بنویسید: `ir.hamshagerdionline.app`
3. App nickname: `همشاگردی` ← Register app.
4. دکمه‌ی **Download google-services.json** را بزنید. بقیه‌ی مراحل آن صفحه را رد کنید (Next، Next، Continue).

## ۳) گذاشتن فایل در GitHub Secrets
1. فایل `google-services.json` را با Notepad باز کنید، همه را انتخاب (Ctrl+A) و کپی (Ctrl+C) کنید.
2. در گیت‌هاب، مخزن ← Settings ← Secrets and variables ← Actions ← **New repository secret**.
3. Name: `GOOGLE_SERVICES_JSON` ← Secret: متن کپی‌شده را بچسبانید ← Add secret.

از ساخت بعدی APK، اعلان گوشی در اپ روشن است.

## ۴) کلید سرور برای وردپرس (حساب سرویس)
1. در Firebase، چرخ‌دنده ⚙️ کنار Project Overview ← **Project settings** ← زبانه‌ی **Service accounts**.
2. **Generate new private key** ← Generate key. یک فایل JSON دانلود می‌شود.
3. در پیشخوان وردپرس: **تنظیمات ← اعلان اپ**. متن کامل این فایل را (با Notepad باز، کپی) در کادر بچسبانید و ذخیره کنید.
4. فایل دانلودشده را بعد از این کار از کامپیوتر پاک کنید.

## ۵) آزمایش
1. APK جدید را نصب کنید، وارد شوید و اجازه‌ی اعلان را بدهید.
2. از گوشی دیگری (یا سایت) برای این حساب پیام بفرستید یا غیبت ثبت کنید؛ باید اعلان روی گوشی بیاید.

اگر نیامد: در «تنظیمات ← اعلان اپ» وضعیت آخرین ارسال نوشته می‌شود؛ متن خطا را برای من بفرستید (نه خود فایل‌ها).
