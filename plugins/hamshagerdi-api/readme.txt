=== API موبایل ===
Version: 2.2.0
Requires PHP: 7.4
REST API با JWT برای اپ موبایل «همشاگردی». مستندات کامل: API.md

نیازمندی‌ها: مدیریت کلاس ≥ 1.7.3، کاربران و عضویت ≥ 2.6.3 (ورود پیامکی و تکمیل ثبت‌نام).
اختیاری: ساختار مدیریت مدرسه ≥ 2.2.1، پنل والدین (مجوزها)، پنل دانش‌آموز (رمز ۴ رقمی)، مقالات (مجله).

== Changelog ==
= 2.2.0 =
* اتصال والد فقط با «کد اتصال والد» (۸ نویسه، مخصوص هر دانش‌آموز) در POST /children/join؛ کد کلاس همچنان با نام فرزند.
* پیشنهادهای اتصال (معلم شماره‌ی والد را ثبت کرده): GET /children/proposals و POST /children/proposals/{id} با accept.
* /classes/{id}/students: تعداد والدین متصل و امتیاز کل؛ /classes/{id}/students/{sid}: کد اتصال والد برای معلم؛ متن آماده‌ی دعوت والد هنگام افزودن دانش‌آموز.

= 2.1.0 =
* جدید: ساخت کلاس از اپ (POST /classes) با همان قواعد سایت، و GET /classes/options (پایه‌ها، استان‌ها، پیش‌فرض‌ها).

= 2.0.0 =
* امنیت: داده‌های فرزند (/children/{id} و همه‌ی مسیرهای والد) فقط با اتصال واقعی والد ↔ فرزند و مجوز همان بخش (HSPP_Perms::can) برمی‌گردد. بخش بسته در فهرست locked می‌آید.
* امنیت: تکالیف، اطلاعیه‌ها و پیام والد با معلم مجوز «تکالیف»، «اطلاعیه‌ها» و «پیام به معلم» را رعایت می‌کنند؛ گفت‌وگوی رابطه‌ی قطع‌شده دیگر دیده نمی‌شود.
* امنیت: حساب‌های مدیریتی سایت و حساب‌های تعلیق‌شده از اپ توکن نمی‌گیرند؛ توکن‌های قبلی‌شان هم باطل است.
* امنیت: تغییر رمز، تعلیق، رد عضویت یا حذف کاربر همه‌ی نشست‌های اپ را باطل می‌کند.
* امنیت: سقف تلاش ورود با رمز برای هر حساب (از هر IP) و برای هر IP؛ سقف برای رفرش، پیوستن با کد کلاس، پیام و تنظیم رمز فرزند.
* امنیت: JWT فقط برای مسیرهای /hamshagerdi/v1 پذیرفته می‌شود (نه /wp/v2).
* امنیت: /school برای عضو کادر بدون اجازه‌ی نظارت فقط نام مدرسه را می‌دهد؛ مدیر تأییدنشده مدیر حساب نمی‌شود.
* امنیت: توکن دستگاه فقط به یک حساب تعلق دارد و با خروج پاک می‌شود. DELETE /devices.
* جدید: ورود با پیامک POST /auth/otp/request و /auth/otp/verify (همان منطق و محدودیت‌های سایت، Pinova، hsum_mobile_known).
* جدید: GET/POST /onboarding (همان HSUM_Onboard).
* جدید: /children/join (کد کلاس یا QR)، /children/requests، /children/{id}/today، /children/{id}/week، /children/{id}/pin.
* جدید: /classes/{id}، /classes/{id}/students/{sid}، /classes/{id}/attendance/week، /classes/{id}/invite (QR والدین و کارت کلاس).
* جدید: /articles، /articles/{id}، /articles/filters.
* رفع: معلمی که خودش والد هم هست، فرزندانش را در /children می‌بیند.
