مدیریت کلاس، حضور و غیاب، امتیاز، ارتباط با والدین، ارزیابی، تکلیف، پورتفولیو، کاربرگ، تقویم مناسبتی و ربات بله برای مدارس.

== فونت‌ها ==
وزیرمتن (متن) و لالزار (تیتر ویژه) با مجوز SIL OFL؛ w_Lotus (عنوان‌ها و عددها) متعلق به MaryamSoft.com و تابع مجوز خریداری‌شده توسط مالک سایت است (پوشه assets/fonts).
